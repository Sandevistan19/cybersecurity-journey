# Lessons Learned

Honest documentation of mistakes I've made, why they happened, and what I changed as a result.

This folder exists because judgment matters as much as technical skill in this field. Catching and correcting an error — and being able to explain why it was wrong — is a skill in itself, and one worth showing, not hiding.

## Format

Each entry covers:
- What happened
- Why it happened
- What I did about it in the moment
- The actual lesson (not just "don't do that again," but the underlying principle)
- What I'm doing differently going forward
